# MicroMart frontend

Next.js (App Router, TypeScript, Tailwind v4) frontend for MicroMart. Browse and search products, register/log in, add to cart, check out (the REST → gRPC path through Gateway), watch an order's status resolve through the saga in real time, view your wallet, and (as an admin) create categories/products, adjust stock, and seed a customer's wallet.

See `setup.md` for configuration, how CORS is avoided entirely, and a full manual test flow.
